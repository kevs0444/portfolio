# Design System Rules

- **Strict Aesthetic:** Bespoke **Data Analytics & Engineering Dashboard** visual language (dense, purposeful typography, telemetry dots, terminal aesthetic, and structured consoles).
- **Zero Emojis / Memojis:** Never use emojis or Memoji-style graphics in UI buttons, chips, tags, labels, navigation, or placeholders.
- **Minimalist Vector SVGs Only:** Use `1.8px` stroke width, uniform bounding boxes, and monochromatic `currentColor` styling.
- **Media Optimization (Vercel Free Tier):** Always use `preload="none"` on `<video>` tags, static poster frames, and `muted playsInline`.
- **Certifications Rail:** Horizontal snap-scroll rail with `Prev`/`Next` SVG chevrons, subtle edge fade, and tabular-nums counter (`01 / 06`).
